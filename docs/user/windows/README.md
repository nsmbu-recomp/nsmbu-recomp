# Windows

NSMBU on Windows is an x86-64 build for Windows 10 or 11.
It uses Vulkan.

## Release install

Download the Windows zip from [GitHub Releases](https://github.com/nsmbu-recomp/nsmbu-recomp/releases).

Unzip it into a folder you can write to.
Start `NSMBU.exe`.

The first start opens the installer.
Each later start launches the game.

The installer uses the system file chooser.
You can also drag a file into the window and press Enter.

If SmartScreen blocks the app, see [If the system blocks the app](../blocked-app.md).

Player paths, logs, and setup files are in [logs.md](../logs.md).
