# On-screen controls

Android and iOS have no physical Wii U GamePad.
The port draws on-screen buttons and a stick so you can play without a controller.

## Android

The on-screen layout covers the GamePad face buttons, the D-pad, the sticks, and the system buttons.
It acts as player 1's GamePad.

Open **Settings → Controls** to change layout and opacity.
**Phone vibration** can rumble the phone when the game requests it.

A Bluetooth controller hides the touch controls while it stays connected.
Plug in a controller the same way.

See [Android](../user/android.md) for install, heat, and logs.

## iOS

Touch controls use Wii U labels.
The left stick appears where you first touch the left side of the screen.
Sliding from one button to another presses the button under your finger.

The controls hide while a Game Controller is connected.
`NSMBU_TOUCH_CONTROLS=1` always shows them.
`NSMBU_TOUCH_CONTROLS=0` always hides them.

Two buttons at the top centre open **Settings** and switch the GamePad picture mode.

See [iOS](../user/ios.md) for install and platform limits.
