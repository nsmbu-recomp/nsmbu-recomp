# Sound and language

## Sound

Open **Settings → Audio**.

- **Mute** — stops host output.
  Press <kbd>M</kbd> in game to toggle mute.
  The choice is saved.
- **Volume** — host output gain from 0% to 100%.
- **Output** — which game mix plays on your speakers:
  - **Auto** follows the game's Off-TV Play faders.
  - **TV** plays only the TV mix.
  - **GamePad** plays only the GamePad mix.

`NSMBU_NO_AUDIO=1` mutes for one start.
`NSMBU_AUDIO_VOLUME` and `NSMBU_AUDIO_OUTPUT` override volume and output for one start.

## Console language

The game reads the Wii U console language only when it starts.
Open **Settings → About → Console language** and pick a language that your disc carries.
Restart the game to apply a new choice.

`NSMBU_LANGUAGE` sets the language for one start when you need it for testing.
